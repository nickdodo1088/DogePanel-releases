# 网站创建与站内证书申请

> 文件位置采用逻辑相对路径；执行历史示例前，请按[路径约定](path-conventions.md)替换为当前机器配置。

## 现状与目标

本机实拍确认：创建窗口默认一键部署，静态网站与运行环境重复入口；HTTPS 页面只有已有证书与手动导入，申请和绑定需要跨页操作。参考用户提供的 aaPanel 建站、HTTPS 截图，沿用 DogePanel 的配色、紧凑表单与下划线选项卡。

## 实施清单

- 每次打开默认「新建网站」，默认静态。普通建站表单统一选择静态、PHP、Node.js、Java、Go、Python、.NET；PHP 展示已安装版本，其他语言选择已有运行环境。后端原有 static/runtime 类型保持兼容。
- 域名、网站类型、版本与目录放在主要区域；分组、FTP、数据库、模板等保留，一键部署放最后。切换类型清除不适用的字段与校验；窗口保持稳定高度。
- HTTPS 页面分为「免费证书」「已有证书 / 手动导入」「连接设置」。免费证书在本页选域名、ACME 账号、HTTP 或 DNS 验证；可原地添加账号。
- 后台持久化申请与网站绑定意图。申请成功后自动应用到网站，自动续期复用原有机制；关闭页面仍继续执行。失败保留正在使用的证书，显示失败信息，可重试。新申请不得覆盖用户后来手动选择的证书或已关闭 HTTPS 的操作。
- HTTP 验证提示公网 80 端口要求；通配符采用 DNS 验证。域名必须属于当前网站；普通证书申请不增加 MFA 门槛，不允许借申请功能执行 Shell。

## 验证与交付

验证默认入口、语言切换、PHP 版本与实际请求、关闭重开、已有部署功能、站内申请成功 / 失败 / 重试、自动绑定与旧证书保护、轮询清理和暗色 / 窄屏布局。后端测试使用隔离数据和受控签发结果，不在本机消耗真实 CA 配额或修改业务网站。构建后更新现有本机面板，保持 dp.44；记录回退点和实拍结果。

## 依据

- [Let’s Encrypt 验证方式](https://letsencrypt.org/docs/challenge-types/)：HTTP-01 固定公网 80，通配符须使用 DNS-01。
- [Vue 异步副作用清理](https://vuejs.org/guide/essentials/watchers.html#side-effect-cleanup)：过期请求结果与轮询必须停止或忽略。

本轮原图、DOM 与请求检查存放在 `PRIVATE_DIR/dogepanel-handoff/codex-website-create-https-20261116/`。

## 本轮验证结果

- 已合并普通建站入口，静态默认，PHP 及其他运行环境在同一表单选择，一键部署排最后；保留代理、子网站及 TCP/UDP 入口。
- HTTPS 页面可直接申请、自动部署和自动续签，支持 HTTP、DNS 自动 / 手动验证及原地添加账号；申请进度持久化，切走页面停止浏览器轮询，重新打开恢复状态。连接设置与证书选择分开。
- 后端回归覆盖关闭浏览器后部署、重复申请、域名归属、后来的手动选择优先、申请失败和重载失败恢复证书文件。新数据库字段迁移可重复执行，既有证书保持不变。使用受控签发结果测试自动部署，不在本机重复申请业务证书。
- Core / Agent 全部 Go 测试、相关 race / vet、前端类型检查 / ESLint / Prettier、39 项前端单元测试及相关浏览器回归通过。首次相关浏览器 43 项通过，样式调整后重跑直接影响用例。
- 本机预览保持 `v2.3.2-dp.44`，只更新面板程序；业务进程和原生配置保持一致。原图、回归结果、实际截图、部署与清理清单保存在本文前述私有目录。

本机实际登录检查已通过，相关 API 无失败请求。创建页、HTTPS 免费证书页和 ProxySQL 第二步业务账号表单均已保存并人工检查截图。本轮清理完成任务的重复程序和旧回退副本约 1.13 GiB，保留最新两份完整配套回退、最近两版升级 original、源码差异、测试结果、脚本和依赖缓存。清单：私有工作目录下 `cleanup.json`。
