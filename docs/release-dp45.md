# dp.45 多账号数据库连接与建站流程

> 文件位置采用逻辑相对路径；执行历史示例前，请按[路径约定](path-conventions.md)替换为当前机器配置。

版本：`v2.3.2-dp.45`。

## 修改

- ProxySQL 初始化向导按数据库地址、业务账号与监控、检查配置分步。支持多个 `mysql_users` 账号，分别填写密码、默认数据库、连接数和备注，监控账号独立配置。
- 逐个验证每个业务账号在目标主库与从库上的登录及选库权限，验证失败不写配置；新模板按用户名限制读写规则。旧的单账号请求继续兼容，已配置实例通过管理页维护，不覆盖现有配置。
- 创建网站默认进入新建网站并选择静态，PHP、Node.js、Java 等在同一表单选择，保留反向代理、子网站和 TCP/UDP 入口，一键部署排最后。
- 网站 HTTPS 页面可直接申请免费证书，并在后台签发成功后自动部署；支持 HTTP、自动与手动 DNS 验证、原地添加 ACME / DNS 账号和自动续期。证书选择、连接设置各自分组。
- 持久化证书部署意图，关闭页面后继续运行，重新进入可查看进度；重复申请、域名归属、后来的手动证书选择均有校验。签发失败保留当前证书，配置检查或重载失败恢复证书文件与主站配置。

## 验证与升级

发布前已部署本机预览，版本保持 dp.44；实际账号重新登录，创建、HTTPS 和 ProxySQL 多账号表单均通过，API 失败请求 0。业务进程、41 份原生配置和 Core 非 root 身份保持一致。

隔离环境复用已验证的 ProxySQL 3.1.12，两个业务账号使用不同密码与默认库，验证普通 SELECT 走读库、锁定读和 UPDATE 走写库，第二个账号错误密码时保持空配置，且不能读取第一个库。证书部署使用受控签发结果验证，未重复申请业务证书。

Core / Agent 全部 Go 测试、相关 race / vet、类型检查、ESLint、Prettier 和 39 项前端单元测试已通过；相关浏览器回归已通过。正式签名包公开前需通过全套浏览器、资产摘要及签名、迁移升级和重复升级验收。

升级只更新面板 Core / Agent，无需重编译 PHP、MySQL、OpenResty 或 ProxySQL。新增证书部署字段采用兼容迁移，保留已有证书和网站。

设计与实施依据：[ProxySQL 账号模型](proxysql-account-model.md)、[网站创建与 HTTPS 流程](website-create-https-ux.md)。
