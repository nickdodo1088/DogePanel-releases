# DogePanel 部署与日常使用

按顺序完成准备、安装和首次登录，再安装需要的软件。无需先编译面板，也无需记住所有命令；服务器上的 `dgpctl` 提供中文数字菜单。

## 1. 安装前准备

1. 准备 Linux 服务器，新部署推荐 Debian 12 / 13。面板提供 amd64、arm64 发布包；应用版本和安装方式以对应页面的支持范围为准。
2. 使用 SSH 登录服务器。已有 root 权限可直接操作；sudo 用户先执行 `sudo -i`。
3. 向维护者索取**安装密码**。它用于解密发布包，不是安装结束后生成的面板登录密码。
4. 确保能够通过 HTTPS 下载 GitHub 发布附件，并能管理云服务器安全组。已有网站、数据库或其他面板时先做备份，再使用对应迁移流程。

Debian 缺少下载工具时，可先安装基础工具：

```bash
apt-get update
apt-get install -y ca-certificates curl openssl
```

本指南中的命令在服务器终端执行。文件位置采用[相对路径与目录别名](../path-conventions.md)，不包含维护者机器上的真实路径、密码或密钥。

## 2. 下载并安装

逐行执行：

```bash
mkdir -p dogepanel-install
cd dogepanel-install
curl -fL --proto '=https' -o quick_start.sh https://github.com/nickdodo1088/DogePanel-releases/releases/latest/download/quick_start.sh
bash quick_start.sh
```

看到安装密码提示后输入维护者提供的密码，按回车。输入时不回显属于正常情况。下载、签名校验、解密、安装及启动由脚本处理；出错时保留错误信息，修复原因后重试。

安装结束后保存：

- 完整访问地址：包含 **HTTPS、端口和安全入口**；
- 面板用户名；
- 面板登录密码。

端口、入口、账号和密码随机生成。默认启用 HTTPS 并生成独立自签证书；TLS 检查失败会报错，不会静默改用 HTTP。

### 可选安装方式

普通用户使用上面的默认命令即可。需要改变安装选项时，在 `bash quick_start.sh` 后加参数：

| 参数 | 用途 |
| --- | --- |
| `--skip-docker` | 先不安装 Docker；本机软件和网站仍可使用，需要容器时再在面板安装 |
| `--interactive` | 逐项选择端口、入口、账号、密码及 Docker |
| `--port 8443` | 指定面板端口；先确认端口空闲并放行云安全组 |
| `--language zh` | 设置面板初始语言；`dgpctl` 的语言单独选择 |
| `--version <版本号>` | 指定正式版本，版本号从发布页复制 |
| `--release-password-file ./release.password` | 从私有文件读取安装密码；文件先用 `chmod 600 ./release.password` 限制权限 |

例如仅安装面板和本机软件所需基础功能：

```bash
bash quick_start.sh --skip-docker
```

不要把密码直接写在命令行或聊天记录中。自定义配置、其他面板接管和旧版本升级前先备份；不要在已有面板目录上当作新服务器重装。

### 服务器无法下载 GitHub 附件

1. 在可下载的可信电脑上，从同一[正式版本](https://github.com/nickdodo1088/DogePanel-releases/releases)下载 `quick_start.sh` 与对应架构的加密安装包。
2. 通过 SFTP 上传到服务器同一个工作目录。x86_64 使用 `amd64`，aarch64 使用 `arm64`。
3. 以 root 在该工作目录执行以下示例，将文件名中的版本和架构换成实际下载的名称：

```bash
bash quick_start.sh --package ./1panel-<版本>-linux-<架构>.tar.gz.enc
```

安装器继续进行校验和解密。脚本与附件应来自同一版本；不要绕过校验，也不要从陌生网站下载替代文件。

## 3. 第一次打开面板

1. 在云服务器安全组中放行安装结果显示的面板 TCP 端口，不要直接关闭系统防火墙。
2. 在浏览器输入完整地址。NAT 云主机显示内网地址时，将 IP 替换为服务器公网 IP，保留端口和安全入口。
3. 自签证书首次访问会提示不受信任。确认访问的是自己的服务器后继续；之后可在面板安全设置中更换受信任证书。
4. 使用安装结果中的用户名和登录密码登录。

访问失败时先按[故障排查](#10-常见问题与排查顺序)检查，不要反复重装或删除已有数据。

## 4. 安装软件并创建网站

1. 打开“应用商店”，按需要安装 OpenResty、PHP、MySQL 或 Redis。支持多种安装方式时，在弹窗中选择；无对应预编译包时使用页面提供的可用方式。
2. 等安装任务完成，再进入软件管理。关闭窗口不会终止后台任务；再次打开可看状态和日志，不要重复安装。
3. 打开“网站”创建网站。默认可创建静态网站；需要 PHP 时选择 PHP 类型和已安装分支。
4. 选择或输入相对目录，例如 `product/member_api`。面板将其限制在配置好的网站根目录内，并准备受管权限。
5. 上传代码。ThinkPHP、Laravel 等按实际结构选择 `public` 等运行目录；前端静态构建可选择 `dist`。
6. 绑定已解析到服务器的域名，在网站 HTTPS 设置中申请免费证书或配置已有证书。

域名页面只维护绑定名称；HTTP 与 HTTPS 分别控制启用状态和监听端口。在本站 HTTPS
页面选择、上传或申请证书，不必先跳转全局证书管理。HTTPS 证书管理可查看每个域名的
覆盖与到期状态，筛选异常并管理续期。修改端口后还需确认云安全组及服务器防火墙放行。

PHP 扩展在对应分支中安装。应用需要 Redis 的 igbinary 序列化时，安装 igbinary，并让 Redis 扩展带对应支持重新编译；网站必须实际使用该 PHP 分支。

网站的上传、资源与错误处理、Session 安全可以继承软件全局设置，启用单独设置后才覆盖。优先使用表单管理 FPM 和 PHP 参数，确有需要再使用高级配置。

## 5. 数据库和备份

- **MySQL**：在管理页配置账号、监听和性能参数。修改 root 密码使用专用密码操作，不等同于保存其他参数。二进制日志及复制功能按实际需要开启。
- **phpMyAdmin**：先确认使用的 PHP 和 MySQL 服务正常；登录错误分别核对密码、账号允许来源和实际数据库实例。
- **ProxySQL**：单机向导可按主机组 10（读写）和 20（只读）配置。后端复制关系需先准备；ProxySQL 路由不等于创建主从复制。参阅[账号模型](../proxysql-account-model.md)。
- **备份**：先配置位置、执行一次手动备份并验证恢复方式，再设置计划。不要通过直接删除数据库文件、网站目录或升级原件释放空间。

不要直接删除 `ibdata1` 等数据文件。相关维护使用[数据库空间回收流程](../mysql-space-reclaim.md)。

## 6. dgpctl 数字菜单

在 SSH 终端输入：

```bash
dgpctl
```

默认中文，输入编号后按回车。完成后可继续操作；`0` 返回或退出。菜单 34 或 `dgpctl --language en` 可切换本次调用语言，不更改网页语言。

| 编号 | 操作 | 何时使用 |
| --- | --- | --- |
| 1 / 2 / 3 | 重启 / 停止 / 启动面板 | 只操作面板程序，停止需确认 |
| 4 | 重载面板核心 | 重新加载核心配置 |
| 5 / 6 | 修改密码 / 用户名 | 忘记密码或更换账号 |
| 8 | 修改面板端口 | 修改后同步云安全组 |
| 9 / 10 | 清除会话 / 临时锁定 | 撤销旧登录或恢复临时锁定 |
| 12 / 13 | 取消域名绑定 / IP 限制 | 错误配置导致无法登录时恢复 |
| 14 | 查看访问地址和账号 | 忘记入口、端口或用户名 |
| 20 / 21 / 22 | 状态 / 版本 / 最近日志 | 查询运行情况和错误 |
| 24 | Google 动态密码 | 查看、绑定、测试、重置或关闭 |
| 25 | 清除通行密钥 | 恢复无法使用的 Passkey 登录 |
| 27 | HTTPS 设置 | 开启 HTTPS 或处理证书问题 |
| 28 / 29 | 修改 / 取消安全入口 | 修改入口或恢复访问 |
| 30 | IPv4 / IPv6 监听 | 调整面板监听方式 |
| 31 | 面板自检 | 检查服务、通信、端口和磁盘 |
| 32 | 普通运维模式 | 管理员限制网页危险操作 |
| 33 | 管理员 Shell 任务 | 在可信终端维护执行内容 |
| 34 / 35 | 语言 / Debian 自动维护 | 切换语言或管理系统更新 |
| 36 | 建立 rkhunter 基准 | 确认系统状态可信后记录文件基准 |

可直接输入 `dgpctl 14`、`dgpctl 24`、`dgpctl 35`。菜单和服务命令只重启面板程序，不作为重启业务应用的入口。

查看日志和服务状态可用文字命令：

```bash
dgpctl status
dgpctl logs core
dgpctl logs agent
dgpctl doctor
```

需要查某个子命令的选项时执行 `dgpctl mfa --help`、`dgpctl maintenance --help`。全部菜单说明见[命令行菜单](../dgpctl-menu.md)。

### 忘记登录地址或密码

```bash
dgpctl 14
dgpctl 5
```

先查看地址和账号，需要时选 5 设置新密码。已经使用过的密码不能靠查看命令还原。

### Google 动态密码

执行 `dgpctl 24`，选择：

1. 查看启用状态；
2. 在当前终端显示绑定二维码和手动密钥；
3. 新建绑定，用 Google Authenticator 扫码，再输入手机上的 6 位动态码；
4. 测试动态码是否有效；
5. 重新绑定，只有新动态码验证成功才替换旧密钥；
6. 关闭动态密码并清除绑定。

对应文字命令：

```bash
dgpctl mfa status
dgpctl mfa show
dgpctl mfa bind
dgpctl mfa verify
dgpctl mfa reset
dgpctl mfa disable
```

二维码和密钥只在真实终端显示，不能通过管道导出。验证码输入不回显，不应放到命令行参数中。变更成功后原面板登录会退出；测试动态码不会消耗登录验证码。旧命令 `dgpctl reset mfa` 仍兼容，表示关闭并清除绑定。

### 普通运维与 Shell 任务

菜单 32 的限制由服务器管理员控制，网页即使通过动态密码也不能越过它。启用后网页终端关闭，文件管理受网站目录约束，Shell 内容由终端维护。

菜单 33 管理可信 Shell 任务。脚本内容、执行身份和执行上限由服务器管理员确定；网页可在允许范围内调整时间、暂停或启用，不可改写脚本。需要恢复高危网页功能时，由 root 在菜单 32 调整策略。

## 7. 升级面板

升级前确认没有安装、备份或证书申请任务，并完成必要备份。

**网页升级**：在面板设置中检查更新、阅读说明后安装。升级会重启面板；服务就绪后刷新并重新登录，检查网站和数据库仍然可用。

**终端升级**：重新下载最新入口并执行：

```bash
curl -fL --proto '=https' -o quick_start.sh https://github.com/nickdodo1088/DogePanel-releases/releases/latest/download/quick_start.sh
bash quick_start.sh
```

已安装时脚本会走升级流程。需要解密密码时使用原安装密码。升级更新程序、`dgpctl` 和语言文件，保留端口、入口、网页语言及账号设置。旧 HTTP 安装保留原协议，需管理员明确开启 HTTPS；新安装默认 HTTPS。

### 首次迁移到 `v2.3.2-dp.003`

从旧短编号（例如 `v2.3.2-dp.49`）或过渡编号 `v2.3.3-dp.001/002` 迁移时，先保留面板及网站备份，再从服务器终端执行一次以下命令。脚本会校验发布包，并根据现有安装进入升级流程。迁移完成后可在网页继续检查更新。

```bash
curl -fL --proto '=https' -o quick_start.sh https://github.com/nickdodo1088/DogePanel-releases/releases/download/v2.3.2-dp.003/quick_start.sh
bash quick_start.sh --version v2.3.2-dp.003 --force
```

升级后检查：

```bash
dgpctl version
dgpctl status
dgpctl doctor
```

新版本无法启动时，升级脚本尝试回退。手工恢复可执行 `dgpctl restore`，前提是保留了可用的升级原件和配套数据库；不要在未备份时删除它们。

## 8. Debian 每日自动维护

该功能维护**当前 Debian 大版本的官方软件包**，不代替 PHP、OpenResty 等面板编译软件的版本管理。

1. 以 root 运行 `dgpctl 35`。
2. 选择启用、镜像区域、更新范围和每日时间。
3. 等待原生组件准备及模拟检查成功。
4. 以后每天自动安装普通更新，无需面板逐次确认。网页“工具箱 → 系统维护”可看状态和日志。

默认自动识别区域：海外使用 Debian 官方 HTTPS，大陆选择阿里云公开 HTTPS，仍验证 Debian 官方签名。源、索引和缓存独立，不覆盖管理员已有系统源。

自动维护排除内核、引导器、固件、initramfs 工具和 DKMS；不自动重启，不跨 Debian 大版本升级。已有内核待重启时，只显示提示和检查结果，由管理员单独处理。

```bash
dgpctl maintenance status
dgpctl maintenance enable --at 03:00 --region auto --channel stable
dgpctl maintenance check
dgpctl maintenance run
dgpctl maintenance logs --job 任务ID --cursor 0
dgpctl maintenance disable
```

`check` 只检查和模拟，`run` 立即维护，任务 ID 从状态或日志页查看。暂停不强杀正在运行的包事务，并恢复系统此前的原生升级调度；不等于关闭管理员另外配置的全部自动更新。Debian 11 已结束官方 LTS，不能当作持续有官方安全维护的系统自动启用；跨大版本升级由管理员另行安排。

## 9. 文件和目录管理

网站根目录前缀在高级设置中管理，具体站点填写相对目录，例如 `product/member_api`。不要对整个软件目录递归修改权限或设置 777。

公共父目录、管理员上传账号和网站 PHP 用户承担不同职责，面板按受管目录准备权限。移动目录后检查运行目录、代码权限及 PHP 目录访问限制。完整路径由当前服务器配置决定，本指南不固定维护者机器上的目录。

## 10. 常见问题与排查顺序

| 问题 | 先检查什么 |
| --- | --- |
| 面板打不开 | HTTPS 地址、随机端口和入口、云安全组、`dgpctl status` |
| 忘记账号或入口 | `dgpctl 14`；忘记密码使用 `dgpctl 5` |
| 动态码不正确 | 手机与服务器时间、是否选对绑定；用菜单 24 测试或重新绑定 |
| 安装窗口关了 | 回到软件管理查看后台任务，避免重复安装 |
| 网站 502 | OpenResty、所选 PHP/FPM 状态、运行目录和错误日志 |
| 数据库连接失败 | 实际实例、端口、监听、账号来源限制、密码和服务状态 |
| 系统维护失败 | 维护日志中的签名、网络、空间、锁冲突或 dpkg 错误；不要删锁文件强行重跑 |
| 网页终端或 Shell 被禁用 | 管理员是否启用了普通运维模式；由 root 在菜单 32 查看 |

反馈时提供版本号、操作步骤、出错接口和脱敏错误，不发送密码、Token、Cookie、私钥或动态密码密钥。先保留错误与备份，再决定修复或回退。

## 11. 卸载与保留数据

确认已经导出需要的数据库、网站、账号设置和备份后，再运行 `dgpctl uninstall` 并逐项阅读确认。卸载面板程序不等于卸载业务软件或清空网站。数据删除不可作为普通故障修复步骤；恢复面板时还需要与原程序配套的数据库、配置和安装密码。
