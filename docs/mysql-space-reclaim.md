# MySQL 系统表空间回收

> 文件位置采用逻辑相对路径；执行历史示例前，请按[路径约定](path-conventions.md)替换为当前机器配置。

日期：2026-11-08。入口：MySQL 设置 → 表空间优化 → 回收系统表空间。适用于面板管理的独立 MySQL 8.0.29 及以上的 8.0 分支、8.4 分支实例，自动识别本机与绑定数据目录的 Docker 安装。

## 原理与操作

Oracle MySQL 不能原地缩小 `ibdata1`。面板将完整逻辑导出、在新数据目录重建并校验、切换目录的流程自动化，用户不需要执行 SQL、删除文件或重新创建账号。MariaDB 11.2 起另有 `autoshrink`；不能把这一选项写进 Oracle MySQL 配置。

1. **检查**：展示当前文件占用、共享表、临时空间需求、备份位置及维护影响。检查版本、账号权限、数据目录、挂载、可用空间、复制、加密、插件和持久化参数。不能安全处理的实例显示具体原因，不提供强制绕过。
2. **确认维护**：明确数据库会暂停服务；完整数据库备份、账号、授权、视图、触发器、存储程序和事件由面板处理。停止目标服务后，使用同一版本的私有实例、独立 Unix socket 和禁用 TCP 的方式导出，避免导出后仍有应用写入。
3. **重建并校验**：保留原目录，初始化同版本的新目录，启用独立表空间。完整恢复并核对表数据、账号授权及数据库对象；保留实例 UUID、TLS 材料和原二进制日志。明确绑定共享表空间的业务表先在私有源实例中转为独立表空间，保留转换前的逻辑备份。
4. **切换**：先持久化只读及禁用事件的临时配置，再原子交换数据目录。目标服务启动后再次验证，提交切换状态后才恢复原读写和事件设置。发布新目录之前失败恢复原配置并启动原实例；原子交换成功即视为提交，之后只完成新实例恢复，不自动倒回旧数据，避免丢失新写入。
5. **释放空间**：成功页分别显示新表空间大小和仍保留的旧目录占用。用户再次确认后可清理该次旧目录，真正归还磁盘空间；已验证的完整逻辑备份继续保留。不能把“活动文件变小”冒充“磁盘空间已释放”。

## 任务与恢复

任务关闭弹窗后继续执行，再次打开显示当前阶段，禁止重复启动。后台任务、独占锁及落盘日志记录每次目录切换；面板重启时处理未完成的事务。凭据通过私有描述符传递，SQL、密码和子进程原始诊断不进入命令参数或任务日志。

数据目录必须可在同一文件系统内重命名；拒绝目录挂载点、外置表空间、未知符号链接、复制/GTID、加密、外部插件及不受控的持久化参数。Docker 使用实际镜像 ID，临时实例无网络，保留目标原有的映射和配置。原数据目录及逻辑备份不纳入普通构建清理。

## 验证记录

隔离测试已通过：本机 MySQL 8.0.46 和 Docker MySQL 8.4.13 均从 140 MiB 重建到 12 MiB，原数据目录在确认清理前保留。实际验证普通应用账号登录/授权、读写及触发器、Unicode 与二进制内容、角色、视图/例程/事件、UUID/TLS 和原二进制日志。

两种安装均通过真实服务接口启动后台任务、查询进度、拒绝重复任务以及确认清理，并验证任务记录成功。

两种安装均覆盖恢复导入时取消任务：原实例重新可用、原表数据不丢失；模拟切换后提交记录丢失，继续向前恢复，新写入的数据保留。旧副本清理后完整 SQL 备份仍在。前端覆盖只读检查、停机原因、实例名称确认、后台状态恢复、防止重复启动、缓存页面切走暂停轮询/返回后恢复、清理及失败恢复；浅色、深色和 390px 截图无横向溢出。

临时私有实例限制内存并关闭网络、事件及二进制日志。原数据文件使用与 InnoDB 锁冲突的 OFD 锁，防止其他进程在切换前启动源库写入；无关文件描述符关闭不会释放该保护。诊断尾部最多保留 1 MiB，不跟随符号链接。回收记录只返回阶段与空间信息，不返回原配置和凭据。

当前首批支持标准独立实例；远程数据库、MariaDB、复制/GTID、加密表空间、外部插件、外置持久化目录以及 Docker 命名数据卷等不符合条件时阻止执行。空间检查是保守预算，不是可回收大小承诺；页面分别记录旧副本清理量和文件系统净可用空间变化。备份包含授权信息，保存在面板私有目录，不通过文件下载接口公开。

全套验证通过：Agent/Core `go test ./...` 与 `go vet ./...`、相关 Go race 检查、TypeScript、ESLint、前端 30 项单元测试及 373 项浏览器测试。操作日志和 Swagger 已重新生成。

本机已部署并保持 `v2.3.2-dp.30`。实际重新登录检查 153 个 API 响应，无请求失败或开关类型警告；新页面对停止的 MySQL 仅提供只读检查，没有创建维护日志或启动数据库。两处 MySQL 设置入口均通过验证，弹窗切换高度稳定；9 个业务服务进程、网站探测、现有配置、账户/权限、防火墙和面板 TLS 保持原状。没有提交、推送或发布 GitHub Release。
