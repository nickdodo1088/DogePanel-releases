# dp.002 网站协议设置与本地源码依赖

版本：`v2.3.3-dp.002`，延续当前编号规则，上游审查基线不变。

## 功能与修复

- 网站域名管理只维护绑定名称；HTTP、HTTPS 独立启用、独立地址与端口。HTTP 跳转支持状态码、目标地址/端口、允许及排除域名，保留原请求路径和查询参数。
- HTTPS 使用分组行表单管理 HTTP/2、HTTP/3、TLS、证书与高级参数；在本站选择、上传、申请免费证书，另有按域名搜索、异常筛选及续期管理。
- 采用实际监听配置生成访问链接，保留网站显示名称与 Session 身份。保存校验并发指纹、IP/端口及参数，失败恢复配置、证书、数据库和原运行状态。
- 修复证书参数错误沿用旧表单必填规则，以及证书验证路径内部跳转后被重定向的问题。HTTP 与 HTTPS 并存时向上游传递实际协议。
- 修复缓存页面在保存中切换后一直保持禁用状态。按参考页面检查标签宽度、长文本、端口编辑、明暗主题和窄屏布局。
- Core、Agent 使用本地 DogePanel 模块标识，ACME 源码纳入本仓库并校验完整性；参考代码检查仅读取本地副本，清理继承的远程自动化。
- 并入 Ubuntu 兼容性实测发现的 cgroup 内存预算、首次建站父目录和权限分离后的审计解析修复。测试隔离环境启动、停止流程同步修正。
- 为 Agent 增加明确的静态构建检查，防止动态构建造成私有权限工作进程无法初始化。

## 升级与验证

旧网站升级不自动改监听、不重载业务服务；首次读取兼容旧配置，首次保存后独立维护协议。普通管理无需绑定 MFA；危险操作仍遵守管理员策略。

两个 Go 模块全套测试、静态检查、相关竞态测试，前端类型与单元测试、网站专项浏览器回归，以及 381 项安装器检查已通过。隔离环境完成真实 Nginx 的 12 项协议、错误配置和占用端口回滚检查；未绑定 MFA 的真实浏览器成功保存 HTTP/HTTPS，未出现失败请求。

Ubuntu 22.04、24.04、23.04、23.10 的原生应用结果见 [兼容性验收](ubuntu-compatibility-validation.md)。共享宿主内核的容器不等同于内核启动或 AppArmor 完整验收。独立 dgprasp 候选源码不纳入本次包，保留已验证的正式组件。
